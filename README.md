# SkillPath — Project 1

A responsive frontend learning dashboard built to demonstrate the DecodeLabs Project 1 requirements.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in a browser. No build step or package installation is required.
3. For local development, open the folder in VS Code and use Live Server if available.

## Included
- Semantic HTML5 landmarks and accessible labels
- Mobile-first responsive layout using CSS Grid, Flexbox and media queries
- Mocha / ethereal blue / moonlit grey inspired palette
- JavaScript interactions: mobile navigation, theme toggle, project checklist, course feedback and add-session dialog
- Keyboard skip link and responsive navigation

## Important
This is a frontend-only project. The brief asks for HTML, CSS and basic JavaScript and does not specify a backend, database, authentication, or real course API. Course statistics and content are sample demonstration data, not connected to a server.
